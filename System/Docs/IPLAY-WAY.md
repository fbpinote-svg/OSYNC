# เปิดเกมกันโกงแบบ iPlay (Apex)

เพิ่มเมื่อ 20 พ.ย. 2026 ตามเอกสาร "iPlay เปิดเกมยังไงให้ไม่ติดแอนตี้ชีท" ที่เจ้าของร้านส่งมา

- เอกสารนั้นเป็นของร้านอื่น เครื่องเราไม่มี iPlay จึงไม่ได้ใช้ path หรือไฟล์ของ iPlay
- เอามาแค่หลักการ แล้วทำเป็นสคริปต์ของเราเอง

## ข้อที่เราทำเพิ่ม

| หลักของ iPlay | ของเรา |
|---|---|
| 1 ไฟล์เกมตรงกับของค่ายทุกไบต์ (ตรวจด้วย hash) | `Client-SteamVerify.ps1` ตรวจทุกไฟล์ตามที่**เครื่องนั้น**อ่านจากดิสก์เกม เทียบขนาด + SHA1 กับ manifest ของ Steam |
| 2 ให้ launcher ของค่ายเปิดเกม | เหมือนเดิม: การ์ด Apex ยังเปิดด้วย `steam.exe -applaunch 1172470` |
| 4 เช็กเครื่องก่อนเปิด ไม่ผ่านก็แจ้ง ไม่ข้ามการตรวจ | `Client-GameStart.ps1` เช็ก EA AntiCheat, ไดรเวอร์ที่ EA ห้าม และ test signing |
| 6 ปิดตัวเกมที่ค้างก่อนเปิดใหม่ | `Client-GameStart.ps1` ปิด r5apex / EAAntiCheat ที่ค้าง และหยุดบริการ EAAntiCheatService ที่ค้างอยู่ |

ข้อ 3, 5 และ 7 เรามีอยู่แล้ว: appmanifest / registry, สิทธิ์ผู้ใช้ของ FiveM, และรีบูตแล้วเครื่องสะอาด

## 1. ตรวจไฟล์เกม (Client-SteamVerify.ps1)

```
Client-SteamVerify.ps1 -AppId 1172470            ตรวจ แล้วพิมพ์ผล
Client-SteamVerify.ps1 -AppId 1172470 -Report    ตรวจ แล้วส่งผลมาที่เครื่องแม่
-Quick   ตรวจขนาดทุกไฟล์ + SHA1 เฉพาะไฟล์ชั้นบนสุด (ไม่กี่วินาที)
```

- อ่าน `appmanifest_<AppID>.acf` แล้วเปิด manifest ของแต่ละ depot ใน `<Steam>\depotcache`
- ไฟล์ที่อยู่ในสอง depot นับว่าผ่านถ้าตรงกับ depot ใด depot หนึ่ง
  - เช่น Apex: ไฟล์ EAAntiCheat มีทั้งใน depot เกม (11 พ.ย.) และ depot Javelin (19 พ.ย.)
- บอกไฟล์ที่หาย ขนาดไม่ตรง SHA1 ไม่ตรง และไฟล์ที่ Steam ไม่รู้จัก
- บรรทัดสุดท้ายเป็น `RESULT: FILES OK` หรือ `RESULT: FILES DIFFER (n)`
- **ตอนบูต:** เครื่องที่อยู่ใน `ClientSteamVerify` จะตรวจเกมใน `ClientSteamVerifyApps` เองหลังบูต 4 นาที แล้วส่งผลเข้า `C:\ProgramData\OSYNC\ClientReports` (phase=steamverify-<AppID>)
  - ตั้งอยู่ที่ Client-Install.ps1 ต่อจากรายงาน OSLink
  - อ่านทั้งเกมทุกครั้งที่บูต จึงควรใส่แค่เครื่องทดสอบ
- **ผลบนเครื่องแม่ (20 พ.ย. 00:13):** Apex 10,642 ไฟล์ 67.7 GB ผ่านทุกไฟล์ ใช้เวลา 5:10 นาที (224 MB/s)

## 2. ตัวเปิดเกม (GameStart.vbs → Client-GameStart.ps1)

**รายการเกม:** `Settings\game-start.json` (ตอนนี้มีแค่ `steam-1172470` คือ Apex บน Steam)

- `kill`: ปิดโปรแกรมที่**ค้าง** คือเปิดมาเกิน 45 วินาทีแล้วไม่มีหน้าต่าง หรือหน้าต่างค้าง
  - ตัวที่กำลังเล่นอยู่ หรือเพิ่งเปิดไม่ถึง 45 วินาที จะไม่ปิด
- `stopServices`: หยุดบริการที่ยังรันอยู่ตอนไม่มีเกมเปิด
- `checks`:
  - `ea_anticheat`: บริการ EA AntiCheat ต้องลงแล้ว
  - `javelin_drivers`: ต้องไม่มีไดรเวอร์ที่ EA ระบุชื่อว่าห้าม คือ CPU-Z (cpuz*) และ WinRing0
    - WO Mic และไดรเวอร์ปรับแต่งอื่นจดใน log อย่างเดียว
  - `no_test_signing`: Windows ต้องไม่ได้เปิด test signing หรือ debug
- **ถ้าเช็กไม่ผ่าน:** ลูกค้าเห็นข้อความภาษาไทยบอกเหตุผล แล้วเลือกได้ว่าจะลองเปิดต่อหรือไม่เปิด
  - ไม่ตอบใน 30 วินาที = เปิดต่อ

**การ์ดในเมนู:** `Master-GameList.ps1` เปลี่ยนคำสั่งของการ์ดที่อยู่ใน game-start.json เป็น `wscript.exe "...\System\Client\GameStart.vbs" <id>`

- เก็บคำสั่งเดิมไว้ในช่อง `direct` ของ games.json
- ตั้ง cwd เป็นโฟลเดอร์เกม เมนู "เปิดตำแหน่งไฟล์" จึงยังเปิดโฟลเดอร์ Apex ได้

**Log:** `C:\Users\Public\OSYNC-GameStart.log` และส่งสรุปสั้นๆ มาที่เครื่องแม่ทุกครั้งที่กด (phase=gamestart)

**ทดสอบ:** `Client-GameStart.ps1 -Id steam-1172470 -Check` เช็กอย่างเดียว ไม่ปิดและไม่เปิดอะไร

**ลบเกมออกจาก game-start.json** = การ์ดกลับไปเปิดตรงแบบเดิม (หลังเครื่องแม่สร้างรายชื่อเกมใหม่ และเครื่องลูกรีบูต)

## ทดสอบแล้ว (20 พ.ย. บนเครื่องแม่)

- ตรวจไฟล์ Apex เต็มและแบบเร็วผ่าน ส่งรายงานถึงตัวรับพอร์ต 4670 ได้
- ตัวเปิดเกม:
  - เช็กผ่าน (READY)
  - เปิดผ่าน GameStart.vbs แล้ว Steam รับคำสั่ง `-applaunch 1172470` และส่งรายงาน gamestart ถึงเครื่องแม่
  - เกมยังไม่ขึ้น เพราะ Steam ของเครื่องแม่ถามว่าจะเตะเครื่องอื่นที่เล่น Euro Truck Simulator 2 ด้วยบัญชีเดียวกันไหม ไม่ได้กดยืนยัน
- ตัวตัดสินว่าค้าง: โปรแกรมทดสอบที่ไม่มีหน้าต่างและเปิดมาเกิน 45 วินาที ถูกเลือกปิดถูกตัว
- **ยังไม่ได้ทดสอบบนเครื่องลูก:** ต้องรีบูตก่อน
